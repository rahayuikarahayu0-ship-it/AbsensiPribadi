# Absensi Pribadi Pro — Android

Source project Kotlin + Jetpack Compose untuk Android Studio.

## Membuka
1. Ekstrak ZIP.
2. Buka folder `AbsensiPribadiPro` di Android Studio.
3. Tunggu Gradle sync.
4. Jalankan pada emulator/perangkat Android.

## Fitur versi 1.0
- Dashboard modern
- Absen masuk/pulang
- Jam dan tanggal otomatis
- Catatan
- Riwayat lokal
- Laporan bulanan sederhana
- Permission lokasi/kamera sudah dideklarasikan untuk pengembangan berikutnya

## Catatan
Versi ini adalah fondasi aplikasi profesional. GPS belum menyimpan koordinat dan kamera belum mengambil selfie; keduanya dapat ditambahkan pada tahap berikutnya.
